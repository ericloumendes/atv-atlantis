# ativade de desenvolvimento web III - autobots V

Passos de instalação:
Backend: 
 - Acesse:
 ```
    src/config/connection.ts
 ```
 Configure as opções da sua database.
 - Execute os comandos:
 ```
    npm install

    npm start
 ```

Frontend:
- Execute os comandos:
```
    npm install

    npm start
```

Versão do node: 18x
